# Zen parity: feature inventory

Reference: `zen-browser/desktop`, branch `dev`, commit `541ee55` (2026-10-20), tag `1.23.4b`. This is a development head, not a stable release. The checkout was verified complete: all 2,600 tracked files are on disk.
Target: Orbit (this repository). CEF 152 in Alloy style, native Win32 + Direct2D chrome, SQLite metadata store.

Statuses: NOT INVESTIGATED · INVESTIGATED · NOT IMPLEMENTED · PARTIALLY IMPLEMENTED · IMPLEMENTED · TESTED · BLOCKED · NOT APPLICABLE.
TESTED means the outcome was exercised in the running browser (self-test suites, the UIA check or a manual on-screen check), not just compiled.

## Architecture note (applies to every row)

Zen's chrome is XUL, CSS and JS running inside Firefox (`src/zen/**`, `src/browser/**` patches). None of it can execute in a CEF host. Orbit reproduces each behavior natively in `src/ui/*` and `src/browser/*`. Values come from the reference CSS and prefs (see `ui/theme.h`). Zen's icons are Nucleo icons, whose license forbids redistribution, so Orbit uses the Segoe Fluent Icons that ship with Windows.
